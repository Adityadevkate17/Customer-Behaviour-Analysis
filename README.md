## 📌 Problem Statement

A retail company wants to analyze its customers' purchasing behaviour to improve sales, customer satisfaction, and customer loyalty.

The objective of this project is to analyze customer shopping data and identify meaningful trends and patterns based on customer demographics, product categories, discounts, reviews, seasons, payment methods, and shopping preferences.

The analysis aims to understand customer preferences, purchasing patterns, and factors influencing buying decisions. These insights can help businesses improve customer engagement, develop effective marketing strategies, optimize product offerings, and make data-driven business decisions.

## 🎯 Business Objective

To analyze consumer shopping behaviour and answer key business questions:

- Which customer segments contribute most to purchases?
- Which product categories are most popular?
- How do discounts influence purchasing behaviour?
- How do shopping patterns vary across age groups and seasons?
- What are the preferences for payment methods and shopping channels?
- Which factors influence customer satisfaction and repeat purchases?

## 📦 Project Deliverables

### 1. Data Preparation & Cleaning – Python
- Cleaned and transformed the raw dataset using Pandas.
- Handled missing values and duplicate records.
- Prepared structured data for further analysis.

### 2. Data Analysis – SQL
- Stored and managed customer data using PostgreSQL.
- Wrote SQL queries to answer business questions.
- Analyzed customer segments, product preferences, discounts, and purchasing trends.

### 3. Interactive Dashboard – Streamlit & Plotly
- Developed an interactive dashboard using Streamlit.
- Created visualizations using Plotly.
- Added filters to explore customer purchasing behaviour.
- Presented key metrics, trends, and insights.

### 4. Deployment
- Hosted the PostgreSQL database on Neon.
- Connected the application to Neon using SQLAlchemy.
- Deployed the dashboard using Streamlit Community Cloud.
